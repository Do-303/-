Groq API 키 설정

캐릭터들이 답하려면 Groq API 키가 필요해요. 키는 이 브라우저 안에만 저장되고, Groq 서버로 보낼 때 말고는 어디에도 전송되지 않아요.

키 발급: console.groq.com/keys → Create API Key

🔒 키를 안전하게 쓰는 법
· 키를 코드나 파일 안에 직접 적지 마세요.
· 이 파일을 웹에 그대로 배포해도 내 키는 안 들어가지만, 방문자가 각자 키를 넣어야 해요.
· 키가 노출됐다면 Groq 콘솔에서 바로 삭제하고 새로 발급하세요.
· 공용 PC에서는 '기억하기'를 끄고 쓰세요.

새 캐릭터 추가

대화하고 싶은 캐릭터(페르소나)를 직접 만들어요. '캐릭터 설정'에 적은 내용대로 AI가 연기해요.

프로필

단톡방 만들기

함께 이야기할 친구를 2명 이상 골라요. 말할 때 이름을 부르면(예: "민준아", "강사님") 그 친구가 먼저 대답하고, 안 부르면 여러 명이 돌아가며 대답해요.

멤버

애니 캐릭터 찾아서 추가

이름을 적으면 위키백과(그리고 Groq 웹 검색이 되면 웹)에서 자료를 찾아서, 성격·말투·첫인사까지 정리해 캐릭터로 만들어요.
