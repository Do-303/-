# 💬 한경 부트캠프 톡

> Groq AI로 움직이는 **메신저 스타일 페르소나 챗봇** (모바일 앱 화면)
> 한경닷컴 IT교육센터 UX/UI 실전캠프 6기 실습 프로젝트

부트캠프 매니저·강사·컨설턴트·동기, 그리고 짱구네 떡잎마을 친구들과 1:1 또는 단톡방으로 대화할 수 있어요.
파일 하나(`index.html`)로 동작하고, 설치할 것이 없어요.

---

## ✨ 주요 기능 한눈에 보기

| 분류 | 기능 |
|---|---|
| 대화 | 1:1 채팅 · **단톡방**(여러 캐릭터가 차례로 대답) · 답변 **스트리밍**(글자가 타닥타닥) |
| 캐릭터 | 기본 캐릭터 13명 · **직접 만들기** · **애니 캐릭터 검색해서 자동 생성** |
| 사진 | **Figma 캡처 보내고 피드백 받기** (이미지 이해 모델 자동 선택) |
| 정보 | 부트캠프 공식 과정 정보 · 교육장 근처 **맛집 32곳 / 술집 26곳**(카카오맵 링크) |
| 화면 | 친구 / 채팅 탭 · 다크·라이트 모드 · **포인트 색상 10가지** · 캐릭터별 채팅방 배경 |
| 보안 | API 키는 코드에 없음 · 브라우저에만 저장 |

## 🚀 바로 시작하기

1. `index.html`을 더블클릭해서 **크롬**으로 열어요.
2. 처음 뜨는 창에 **Groq API 키**(`gsk_`로 시작)를 넣고 **연결 확인 후 저장**을 눌러요.
   키 발급: <https://console.groq.com/keys> → Create API Key (무료)
3. 친구 탭에서 캐릭터를 눌러 대화를 시작해요.
   - `Enter` 전송 · `Shift + Enter` 줄바꿈
   - 아래쪽 빠른 질문 버튼을 눌러도 돼요.

> 인터넷 연결이 필요해요. (Groq API, 글꼴, 위키백과 검색)

## 🧑‍🤝‍🧑 캐릭터

### 부트캠프 친구 (4명)
| 캐릭터 | 역할 |
|---|---|
| 박한경 매니저 | 6기 담당 매니저 · 일정·출결·커리큘럼·상담 |
| 윤서진 강사 *(가상 인물)* | UX/UI·Figma 개념 설명, **Figma 캡처 피드백** |
| 정다은 컨설턴트 *(가상 인물)* | 포트폴리오·이력서·면접 코칭 |
| 민준 *(6기 동기, 가상 인물)* | 반말로 같이 공부하는 비전공 동기 |

### 짱구네 떡잎마을 (9명 · 팬 롤플레이)
짱구 😜 · 엄마 봉미선 👩 · 아빠 신형만 🍺 · 짱아 🍼 · 철수 📚 · 유리 🐰 · 수지 💎 · 훈이 😢 · 맹구 🪨

- 각자 성격·말투대로 대답해요. (짱아는 옹알이만, 맹구는 "…응")
- 채팅 탭에 **떡잎마을 방범대 🚨**, **짱구네 가족 🏠** 단톡방이 미리 만들어져 있어요.
- 아이 캐릭터는 연애·위험한 이야기에 아이답게 딴소리로 넘어가도록 규칙을 넣었어요.
- 원작: 우스이 요시토 『짱구는 못말려』. 프로필은 원작 그림 대신 이모지예요.

### 직접 만들기
👤+ 버튼 또는 **새 캐릭터 추가** → 이름 · 한 줄 소개 · 캐릭터 설정(성격·말투·역할) · 첫 인사 · 빠른 질문.
**예시로 채우기**를 누르면 작성 예시가 들어가요. 옵션으로 *부트캠프 과정 정보*, *교육장 근처 맛집·술집 정보*를 켤 수 있어요.

### 🔍 애니 캐릭터 찾아서 추가
1. 친구 탭 → **애니 캐릭터 찾아서 추가**
2. 캐릭터 이름 + 작품 이름(선택) → **찾아보기** (예: 진구 / 도라에몽)
3. **위키백과 공개 API**에서 자료를 찾고, Groq에 웹 검색 모델(compound)이 있으면 웹도 찾아요.
4. AI가 성격·말투·세계관·첫인사·빠른 질문을 정리 → 미리보기 카드 + 출처 링크
5. **이대로 추가하고 대화하기** 또는 **내용 고쳐서 추가하기**

> 자료를 못 찾으면 AI가 아는 정보로만 만들어요. 내용을 꼭 확인해 주세요.

## 💬 대화 기능

### 단톡방
- 채팅 탭 → **단톡방 만들기** → 이름(선택) + 멤버 2명 이상
- **이름을 부르면** 그 캐릭터가 대답해요. (예: "민준아", "강사님", "짱아야")
- 안 부르면 최대 3명이 **순서를 섞어** 차례로 대답하고, 앞사람 말에 반응해요. 할 말이 없으면 알아서 건너뛰어요(PASS).

### 답변 스트리밍
답이 한 번에 뜨지 않고 실시간으로 써져요. 끝에 깜빡이는 커서가 보여요.

### 📎 사진 첨부 (Figma 캡처 피드백)
- 입력창 왼쪽 **+** 버튼, 또는 캡처를 복사해서 입력창에 **붙여넣기**(Cmd/Ctrl + V)
- 사진을 보내면 이미지를 볼 수 있는 모델(Llama 4 Scout / Maverick 등)을 자동으로 골라요.
- 윤서진 강사는 "잘한 점 1개 + 고칠 점 2~3개"를 **px 단위로 구체적으로** 알려줘요.
- 보낸 사진을 누르면 크게 볼 수 있어요.

### 🖼 채팅방 배경
- **자동:** 캐릭터 대표 색이 은은하게 번지고, 캐릭터 이모지가 옅은 무늬로 깔려요. 단톡방은 멤버들 색·이모지가 섞여요.
- **직접:** 채팅방 메뉴 → 배경 사진 고르기 (글씨가 잘 보이게 반투명 막을 깔아요)

## 🌐 배포하기 (웹에 올리기)

> 코드에 API 키가 없어서 그대로 공개해도 **내 키는 안전**해요. 대신 방문자는 각자 Groq 키를 넣어야 대화할 수 있어요.

### 방법 1. GitHub Pages — 포트폴리오용 추천
1. github.com 가입 → **New repository** (예: `hankyung-talk`, Public)
2. **Add file → Upload files** → `index.html`, `README.md` 올리고 **Commit changes**
3. **Settings → Pages** → Branch `main` → Save
4. 1~2분 뒤 `https://아이디.github.io/hankyung-talk` 완성

### 방법 2. Netlify
1. **먼저 netlify.com에 가입·로그인**
2. <https://app.netlify.com/drop> 에 이 폴더를 끌어다 놓기

> ⚠️ 로그인 없이 올리면 넷리파이가 사이트를 **비밀번호로 잠가요.** 이미 올렸다면 화면의 *Claim* 버튼으로 계정에 연결하면 풀려요.

### 방법 3. 파일로 공유
`index.html`을 카톡·메일로 보내면 받은 사람이 크롬으로 열어서 바로 써요.

## 🔒 API 키 보안

- 키는 **코드에 적혀 있지 않고** 브라우저 저장소에만 들어가요.
  - 기본: `sessionStorage` (탭을 닫으면 삭제)
  - '이 기기에 키 기억하기' 체크 시: `localStorage` (계속 유지)
- 키는 Groq 서버(`api.groq.com`)로 요청할 때만 쓰여요.
- 화면에는 `gsk_••••1234` 처럼 가려서 보여줘요.
- 누구나 키 없이 쓰는 서비스로 만들려면 **서버(백엔드)가 키를 보관**해야 해요. (예: Vercel 서버리스 함수)
- 키가 노출되면 Groq 콘솔에서 바로 삭제하고 새로 발급하세요.

## 💾 데이터 저장 위치

모든 데이터는 **지금 쓰는 브라우저**에만 저장돼요. 다른 기기·브라우저에서는 보이지 않아요.

| 저장 이름 | 내용 |
|---|---|
| `groq_api_key` | API 키 (session 또는 local) |
| `groq_model` | 고른 AI 모델 |
| `hk_chat_방ID` | 방별 대화 기록 (최근 60개) |
| `hk_custom_personas` | 내가 만든 캐릭터 |
| `hk_groups` | 단톡방 목록 |
| `hk_bg_방ID` | 방별 배경 사진 |
| `hk_theme` · `hk_accent` · `hk_tab` | 모드 · 포인트 색상 · 마지막 탭 |
